# Super Siesta Landing Page

## تشغيل الموقع محليًا
```bash
npm install
npm run dev
```

## نشره على Vercel
1. ارفع هذا المجلد إلى GitHub.
2. ادخل إلى Vercel.
3. Add New Project.
4. اختر المشروع من GitHub.
5. Build command: npm run build
6. Output directory: dist
7. Deploy.

رقم الهاتف وواتساب موجودان في src/App.jsx.
